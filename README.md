## Zero-Knowledge Engineering

### [zkVM / STARK Prover](https://github.com/SrishtiCode/zkVM)
Educational STARK proving system built from scratch in Rust: finite-field arithmetic, FFT/IFFT, low-degree extension, AIR constraints, composition polynomials, Merkle commitments, Fiat-Shamir transcripts, and FRI folding.

`Rust` `STARKs` `FRI` `AIR` `FFT` `Finite Fields`

### [KZG Polynomial Commitment Scheme](https://github.com/SrishtiCode/KZG-PCS)
KZG implemented from scratch in Rust: SRS and trusted setup, commitments, quotient polynomials, evaluation proofs, and pairing-based verification over BLS12-381.

`Rust` `KZG` `BLS12-381` `Bilinear Pairings`

### zkSync Airbender Research
Studied Airbender, a Rust-based RISC-V zkVM prover, tracing how proof-system theory becomes production code. Also investigated Ethereum execution behavior using execution-spec fixtures and differential testing.

`Rust` `zkVM` `RISC-V` `Ethereum Execution`

### [ZKRoadmap](https://github.com/SrishtiCode/ZKRoadmap)
Open-source, end-to-end learning roadmap for ZK: math foundations → cryptographic primitives → Groth16, PLONK, STARKs, FRI, Halo, folding → zkVMs and prover engineering. I completed it myself before publishing it for others.
